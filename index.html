PROJECT OVERVIEW

About the system

This prototype models tasks as vertices and dependencies as directed edges. It uses Kahn’s topological sorting algorithm to find a valid task order and identifies cycles when no complete order exists.

AlgorithmKahn’s Sort
Time ComplexityO(V + E)
Graph TypeDirected Graph / DAG

Note: this prototype plans task order; it does not compile source code or run tasks in parallel.
